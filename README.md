# CiteRAG

一个支持**引用证据**的中文 PDF RAG 问答系统，并结合小样本 **QLoRA** 微调，探索其在**操作系统**与**计算机组成原理**教材问答场景下的效果。

---

## 1. 项目简介

CiteRAG 是一个面向中文教材场景的 PDF 问答系统。系统以课程 PDF 为知识来源，通过检索增强生成（RAG）回答用户问题，并在回答中给出可追溯的引用证据，例如文档来源、页码、chunk 编号与证据片段。

在完成基础 RAG 系统后，本项目进一步围绕 **操作系统 / 计算机组成原理** 两门课程，进行了小样本 QLoRA 微调实验，用于分析：

- 小样本 LoRA 是否有助于教材风格适配
- response-only loss 监督对齐方式对结果的影响
- 数据纯净度对微调结果的影响
- LoRA 与 RAG 在实际问答系统中的互补关系

本项目不仅关注“系统能不能跑起来”，也关注“实验结论能不能讲清楚”，因此整体设计强调：

- 工程可复现
- 回答可追溯
- 实验可解释
- 结果可展示

---

## 2. 项目目标

本项目的目标包括两部分：

### 2.1 系统目标
构建一个支持中文 PDF 检索问答的 CiteRAG 系统，实现：

- PDF 解析
- 文本 chunk 切分
- embedding 向量化
- FAISS 检索
- reranker 重排序
- LLM 回答生成
- 引用证据输出
- LLM judge 自检

### 2.2 研究目标
围绕操作系统 / 计组教材问答，探索：

- 小样本 QLoRA 是否能提升回答风格一致性
- 数据纯净度与监督对齐方式是否显著影响结果
- 在 3B 级模型上，LoRA 的合理定位是什么

---

## 3. 主要功能

当前 CiteRAG 已支持以下能力：

- 中文 PDF 文档解析
- 按 chunk 切分教材文本
- 使用 embedding 模型进行向量化
- 使用 FAISS 建立向量索引
- 检索 topK 候选 chunk
- 使用 reranker 对候选结果重排序
- 将检索结果作为上下文输入大模型生成回答
- 在回答中输出引用信息
- 使用 LLM judge 进行覆盖度与可信性自检
- 使用 QLoRA 进行小样本领域微调
- 对 Base / LoRA / clean50 / clean100 进行实验对比

---

## 4. 项目亮点

### 4.1 回答带证据引用
与普通问答系统不同，CiteRAG 在输出答案时，会附带证据来源，支持追溯到具体文档与页面，而不是只给出“看起来合理”的生成结果。

### 4.2 检索 + 重排序 + 生成的完整链路
系统不仅进行了基础向量检索，还引入 reranker 对候选 chunk 进行重排序，以提升最终上下文质量。

### 4.3 引入 judge 自检机制
在生成回答后，系统会进一步使用 LLM judge 对答案进行自检，输出如 `coverage`、`unsupported_points` 等信息，用于辅助判断回答是否被证据充分支撑。

### 4.4 小样本 QLoRA 实验具有研究性
本项目并未把 LoRA 仅当作“调一下模型”的工程操作，而是围绕以下问题进行了实验分析：

- response-only loss 对齐是否正确
- 数据纯净度是否关键
- clean50 与 clean100 的差异说明了什么
- LoRA 更适合做知识增强，还是风格适配
